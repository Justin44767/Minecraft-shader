# VERITY development download

`VerityV5-26.3-Fabric-dev.jar` ist der kompilierte Entwicklungsstand für Minecraft Java 26.3, Fabric und Java 25. Auf der GitHub-Dateiseite über die Download-Schaltfläche herunterladen; nicht den Quellcode-ZIP als Mod installieren.

Die Prüfsumme steht in `SHA256SUMS.txt`. Abhängigkeiten, Installation und fehlende Funktionen stehen in der [Projekt-README](../README.md), die durchgeführten Tests im [Testbericht](../docs/TEST_REPORT.md).

Dieser Build ist **keine vollständige VERITY-V5-Horror-Mod**. Unter anderem fehlen Lichtkegel, vollständige Story/Demon-Verwandlung und räumliche Sprachausgabe. Ein Vosk-Sprachmodell ist nicht gebündelt. Essential und echte Voice-/Zwei-Client-Sitzungen wurden nicht getestet.
